# LMS Lite - Система управления обучением

REST API для управления курсами, уроками, студентами и инструкторами. 
Проект реализован на **Java 21 / Spring Boot 3** с использованием **PostgreSQL** и полностью контейнеризирован с помощью **Docker**.

Была сделана вся основная часть + следующие допы:
- PDF-сертификаты
- Docker
- Статистика курсов
- Результаты всех тестов
- Swagger / OpenAPI

Установка: git clone https://github.com/HotWalterInYourArea/lms-lite

Запуск: docker compose up --build
